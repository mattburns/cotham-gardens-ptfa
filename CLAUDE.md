# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Static website for the Cotham Gardens Primary School PTFA (https://cothamgardensptfa.co.uk/), built with Astro + Tailwind. Design goals: free to host, serverless, secure, fast, and editable by non-technical users. Keep it simple — "no magic" is an explicit project goal.

## Commands

- `npm run dev` — format with Prettier, then start the dev server
- `npm run build` — build static site to `dist/`
- `npm run preview` — preview the production build
- `npm run format` — run Prettier over everything
- `npx decap-server` — run a local Decap CMS backend for editing content at `/admin` locally (`local_backend: true` is set in the CMS config)

There are no tests or linter beyond Prettier (configured with `prettier-plugin-astro` and `prettier-plugin-tailwindcss`).

## Deployment

Every push to `main` triggers `.github/workflows/deploy.yml`, which builds the site and deploys it to GitHub Pages. There is no staging environment — `main` is production.

## Architecture

Content and presentation are deliberately separated so non-technical users can edit content:

- **Content lives in Markdown** under `src/content/`:
  - `src/content/events/*.md` — an Astro content collection defined in `src/content.config.ts` (schema: `title`, `eventDate`, optional `image`). Event pages are generated by `src/pages/events/[id].astro` via `getStaticPaths`; the events listing is `src/pages/events.astro`.
  - `src/content/pages/*.md` — per-page content (home, contact, active-travel, events intro), imported directly into the matching `.astro` page (e.g. `index.astro` does `import { Content, frontmatter } from '@content/pages/home.md'`). These are _not_ a content collection.
- **Decap CMS** provides the editing UI at `/admin`. Its config is `public/admin/config.yml` — this defines which files and frontmatter fields editors can touch. **If you add/rename content files or frontmatter fields, update `config.yml` to match** (and `src/content.config.ts` for events). Auth is via DecapBridge (git-gateway backend committing to `main` on editors' behalf), so editors don't need GitHub accounts.
- **Images** uploaded via the CMS land in `src/assets/images/` (the CMS `media_folder`) and are referenced by path in frontmatter.

Path aliases are defined in `tsconfig.json`: `@components/*`, `@layouts/*`, `@content/*`, `@assets/*`.

Layout/styling: single layout in `src/layouts/Layout.astro`, shared components in `src/components/`, brand colors (`brand-yellow`, `brand-green`, `brand-teal-dark`, etc.) and the display font defined in `tailwind.config.mjs`. The visual style is deliberately playful (rounded-3xl cards, emoji icons, bunting).
